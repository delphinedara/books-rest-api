# Books REST API - Architecture

Node.js/Express REST API backed by PostgreSQL.

## Security

- JWT authentication and reader/admin authorization
- Input validation and parameterized SQL
- Helmet security headers and rate limiting

## Automated Testing

- Jest and Supertest API tests
- C# NUnit, Reqnroll, and RestSharp BDD tests

## DevSecOps

- GitHub Actions CI
- CodeQL static analysis
- Gitleaks secret scanning
- OWASP ZAP dynamic security scanning
- Dependency vulnerability auditing
